# SOURCE writer projection: additive precode

The next implementation is a CPU bridge and projection experiment. Diablo VR remains research: the last game capture retains the rectangle and cutouts, and the relevant input, writer and transforms remain unknown. This change executes no new model, ABI probe, compiler, vendor, renderer, Wine, GPU, game or headset.

The [ordered manifest](proposals/owned-source-writer-projection-v1/manifest.json) adopts the frozen C ABI and sink, the exact SOURCE insertion table and the required build-generation addendum, then applies the narrowly named private exceptions in this bundle. Read the manifest and bridge addendum together; the original bridge draft alone is insufficient. Historical drafts and proofs are preserved.

The faithful workload includes both real nested `SetPipelineState(NULL)` calls. The constructor setter precedes command birth; the first-case setter precedes Reset2 RETURN. Neither is filtered, moved or relabeled. The unchanged pure model660 may retain a complete **unknown** report from a valid immutable READY frame. No positive relation is expected for this faithful profile. A real observation, protocol or serialization failure can still refuse the frame.

RootParse admission is tied to the genuine committed pending RootCreate on the SOURCE thread, before root allocation and before conversion or free. A pending PSO alone grants nothing. One embedding C translation unit will include the exact frozen core once and add private operations that can access its internal state. The shader bridge stays stateless and the forwarder has no context. This is a design, not compiled linkage.

GRAPHICS provenance comes from the literal SOURCE callsite and a bounded marker inside already reserved core arena bytes. The exact 64-byte exception, marker states, cookie, freshness checks and closure policy are documented. No public APP input supplies a typed fact, generation, epoch or SOURCE clock. Native callbacks under Draw must preserve genuine command and PSO lineage across admission; a current raw-handle lookup cannot replace that history.

The proposed C SHA-256 utility hashes a complete authorized SOURCE-owned shader span before its original call. Its workspace is 448 bytes, with 288 bytes of immutable constants. Known pointer/count with an unavailable optional digest remains incomplete Code; it does not automatically imply NO_PAYLOAD. Structural pointer checks do not establish readability. The source borrow and lifetime preconditions are explicit at each site.

All wire and sink limits stay fixed: 64 records, 128 marks, 32 pending, 21 object occurrences and a complete 65536-byte raw frame with 4096 nodes, depth20 and strings256 bytes. The unchanged model report cap is 262144 bytes. Conditional source schedules can exceed these bounds; actual raw/node fit remains unproved until a future real serializer result. No truncation, eviction, retagging or cap increase is permitted.

The proposed combined named local-object sums are 4608 bytes under the pending32 ceiling and 2520 bytes under the documented synchronous peak3 condition. They include the new 320-byte guard and 64-byte cookie plus the digest proposal. These are documentary object sums, not measured stack or total CPU memory. The existing 404416-byte context/issuer and existing TLS remain separate.

The next CPU plan is limited to the seven exact private bridge operations, the exact SHA256 API, owned original-signature/POD mocks, a bounded reader and compile-only probes against the already pinned complete vendor headers. The proposed projectors filenames do not define a generic 46-builder API: its signatures and ownership remain a separate contract gate. It must preserve original arguments, typed returns and cleanup in off/on/faulted modes, then consume actual primary ReceiptCopy bytes once with the unchanged model and retain its entire report. Documentary examples are not SOURCE observations. A separate parent admission is required before that implementation starts. Source hooks, patches, vendor configure/build and physical execution remain later gates.
